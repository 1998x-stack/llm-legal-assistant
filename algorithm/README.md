# Algorithm / evidence engine

`backend/app/core.py` provides the initial **deterministic** parser, scope gate and three example issue detectors. It is deliberately not a legal reasoning engine or a trained LLM. Evidence quotes are reconstructed from server-side blocks and source hashes; absence findings have coverage records rather than invented citations.

Next: a versioned, qualified-lawyer-approved NDA playbook, a benchmark over authorized redacted contracts, strict output schemas and a model gateway without tool access. See the [architecture](https://github.com/1998x-stack/projects/blob/main/projects/professional/llm-legal-assistant/design/algorithm-architecture-v1.0.md).
